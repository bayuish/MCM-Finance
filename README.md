# MCM Finance

Platform manajemen keuangan dan bisnis dengan arsitektur kontrol akses terpisah untuk peran **Owner** dan **Admin**.

## Tech Stack
- **React 19 + TypeScript + Vite 8**
- **Tailwind CSS v4**
- **React Router DOM v7** (Array-based routes + Suspense & Lazy Loading)
- **Lucide Icons**

## Role System
- **Owner**: Akses ke laporan keuangan eksekutif & ringkasan analisis bisnis.
- **Admin**: Akses ke manajemen pengguna & operasional sistem.

## Running Locally

```bash
# Install Dependencies
npm install

# Run Development Server
npm run dev

# Build for Production
npm run build
```
